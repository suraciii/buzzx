评审尺寸

检查边界行为

可点选终端，用键盘 v、j/k、PgUp/PgDn、g/G、Enter、Esc 操作。

同一套界面结构

上下文、作者、正文、操作、状态保持固定顺序。24×6 也保留两行正文，范围提示只表示当前消息的显示行数。

同一条消息身份

新消息不会抢焦点。Enter 始终回复正在阅读的消息；存在未发草稿时留在阅读页，提示返回处理草稿。

最小新增能力

只读取已加载文本，复用现有回复链路。搜索旧历史、Markdown 渲染、媒体预览和 Agent 控制留给后续独立设计。

原型使用合成文本；所有评审按钮、尺寸与配色切换均在终端外。它们不是新增产品控件。演示不连接 relay，不发送消息，不代表真实终端或功能已完成验收。
